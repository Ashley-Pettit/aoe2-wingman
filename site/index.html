Age of Empires II: Definitive Edition

Wingman

A small helper that sits on top of the game while you play ranked. Map facts, a scouting report on your opponent, alerts when you forget something, and your record.

Download Wingman.exe Python version (.bat)

Windows only. Free. All releases

Knows the map

Sheep, boar and relics on the map, counted off as you find them.

Scouts your opponent

Their rating, how they usually open, when they usually hit Feudal and Castle, and what beats their unique unit. All from their public games.

Nags you, nicely

Idle Town Center, houses, your Feudal and Castle buildings, and a build order that follows your pop.

Pick how to run it

Wingman.exe

  • Download and double-click
  • Nothing else to install
  • Update by downloading the new one

AoE2 Wingman.bat

  • Needs Python installed first
  • Updates itself from Settings
  • Gets new bits first

Not cheating

It only uses what you can already see: the lobby, your own screen and the public ladder. It never reads the game's memory.

The first time you run Wingman.exe, Windows may say it "protected your PC", because the file is not signed. Click More info, then Run anyway. Full install guide
